# 🎬 CLIP Video Retrieval System

Search for specific moments in videos using **natural language descriptions**. Powered by OpenAI's CLIP (Contrastive Language-Image Pre-training) model.

## ✨ Features

- 🔍 **Text-based video search** - Find frames using natural language
- 🎯 **CLIP embeddings** - State-of-the-art multi-modal understanding
- ⚡ **FAISS indexing** - Fast similarity search
- 🖥️ **Gradio web interface** - Easy to use UI
- 📹 **Frame extraction** - Automatic video processing
